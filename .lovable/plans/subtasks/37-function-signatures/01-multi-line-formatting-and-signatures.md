# Subtask 01 - Multi-Line Parameter & Call Site Formatting

## Parent Specification
[37-function-signatures-audit.md](.lovable/plans/pending/37-function-signatures-audit.md)

## Acceptance Criteria & Requirements
- Verify that function definitions with >2 parameters are formatted one-per-line with trailing commas.
- Verify that call sites with >2 arguments are formatted one-per-line with trailing commas.
- Verify semantic action verbs and affirmative `is`/`has` boolean prefixes.
