## Root cause analysis

Symptom: 404
Trigger: gitmap hd
Root cause: Attempts to download docs-site.zip or fallback to gitmap.dev (which is unrelated and incorrect).
Why it escaped: Hardcoded external URL assumption instead of local port bindings.
Fix: Refactor gitmap hd to serve the markdown docs site on a localhost port and launch the browser directly.
Prevention: .lovable/strictly-avoid.md rule prohibiting gitmap.dev references.
Regression check: gitmap hd serves locally on port 9999 without external HTTP requests.
