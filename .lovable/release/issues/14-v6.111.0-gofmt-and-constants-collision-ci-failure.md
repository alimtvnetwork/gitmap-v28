# RCA: CI Pipeline Failure on gofmt Audit and Constants Collision False-Positive

## Metadata

- **Previous Version**: 6.110.0
- **New Version**: 6.111.0
- **Failing Jobs**: `lint` (gofmt-check) and `constants-collision-check` in `.github/workflows/ci.yml`
- **Status**: Resolved

## Root Causes

1. **Unformatted Go Files (`gofmt -l .`)**:
   - Multiple subtask Go files generated across recent batches were not formatted with `gofmt -w .`.
   - The CI `go-format-check.sh` step failed because `gofmt -l .` returned unformatted filenames.
2. **Constants Collision False-Positive**:
   - `.github/scripts/check-constants-collisions.py` misparsed multi-line string concatenations starting with ANSI constants (`ColorDim`, `ColorReset`) on newlines as duplicate identifier declarations.

## Resolution

1. Executed `gofmt -w .` and `goimports -w` across all packages in `gitmap/`.
2. Enhanced `.github/scripts/check-constants-collisions.py` with multi-line binary operator continuation tracking.
3. Formatted constant expressions cleanly on single lines.
4. Regenerated CLI completion mappings in `gitmap/completion/allcommands_generated.go`.
