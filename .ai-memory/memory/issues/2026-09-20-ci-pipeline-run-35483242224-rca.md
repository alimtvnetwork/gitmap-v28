   - In `cli/store/ssh_repo.go`, wrapper aliases `GetSSHHostByAlias`, `GetSSHHostByIP`, and `ListSSHHosts` were missing.

2. **Coding Policy Failures:**
   - Nested `if` statements at depth 2 violated the policy linter in `cli/cmdssh/ssh_pass_cmd.go`, `cli/cmdagy/agy_fix_pipeline_inject.go`, and `cli/cmdagy/agy_conv_scanner.go`.
   - Negative boolean identifiers `hasNoPass`, `hasNoTranscript`, and `hasNoTag` violated boolean naming standards.
   - Hardcoded local Windows file paths in `cli/helptext/agy.md` violated the relative path check.
3. **Unit Test Regressions:**
   - In `cli/cmdmacro/macro_add_interactive.go`, `handleZeroInteractiveSteps` returned `*apperror.AppError(nil)` causing typed-nil evaluation issues.
   - In `cli/cmdpull/pull_table_test.go`, the test expected `-hiltrax-v4` for 24-character lead truncation.

## 3. Root Cause

1. `cli/cmdagy/agy_ping.go`: Missing import `"github.com/alimtvnetwork/gitmap-v28/cli/result"` and accessing `.Error` instead of `.Err`.
2. `cli/store/ssh_repo.go`: Missing alias forwarding functions.
3. `cli/cmdssh/ssh_pass_cmd.go`: Out-of-sync parameter signatures for DB calls and depth-2 nested conditionals.
4. `cli/helptext/agy.md`: Windows local absolute filesystem paths embedded in example text.
5. `cli/cmdmacro/macro_add_interactive.go`: Go concrete nil pointer returned as `error` interface.
6. `cli/db/sshconnection.go`: SQLite string conversion from `COALESCE` expression failing `time.Time` scan.

---

## 4. Code Fix

1. **`cli/cmdagy/agy_ping.go`**: Added `"github.com/alimtvnetwork/gitmap-v28/cli/result"` and referenced `res.Err`.
2. **`cli/store/ssh_repo.go`**: Added `GetSSHHostByAlias`, `GetSSHHostByIP`, and `ListSSHHosts`.
3. **`cli/cmdssh/ssh_pass_cmd.go`**: Unpacked `(*SSHConnection, error)` from DB calls, extracted `resolvePassTarget` to flatten conditionals, and replaced `hasNoPass` with `hasPass`.
4. **`cli/cmdagy/agy_fix_pipeline_inject.go` & `cli/cmdagy/agy_transcript_parse.go`**: Extracted helpers to flatten nested `if` statements and used positive boolean identifiers `hasTranscript` and `hasTag`.
5. **`cli/cmdagy/agy_conv_scanner.go`**: Extracted `appendMatchingConv` and flattened `extractWorkspaceFromLine` using guard clauses.
6. **`cli/helptext/agy.md`**: Sanitized paths to use relative and portable placeholders.
7. **`cli/cmdmacro/macro_add_interactive.go`**: Changed return type of `handleZeroInteractiveSteps` and `handleZeroPipedSteps` to `error`.
8. **`cli/cmdpull/pull_table_layout.go`**: Removed unused layout helpers.
9. **`cli/cmdpull/pull_table_test.go`**: Updated lead-truncation assertion.
10. **`cli/cmdssh/ssh_exec_install_test.go` & `cli/cmdssh/ssh_login_cmd_test.go`**: Updated platform expectations and test DB reconnection per call.
11. **`cli/db/sshconnection.go`**: Scanned `FirstRunAt` into `sql.NullTime` directly without `COALESCE`.
