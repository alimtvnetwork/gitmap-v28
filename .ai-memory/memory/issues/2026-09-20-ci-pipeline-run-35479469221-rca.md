# Root Cause Analysis (RCA) - CI/CD Pipeline Failure Run #35479469221

> **Target Repository:** `alimtvnetwork/gitmap-v28`  
> **Failing Workflow Run:** `#35479469221`  
> **Commit SHA:** `1303ba71d2e79b6aea1e65e0d2074ea97b928e9f`  
> **Date:** 2026-09-20  

---

## 1. Why It Happened

Recent features and fixes added for SSH power command normalization, macro deployment, and SSH export/import (`cli/cmdssh/`) introduced code style and policy drift, unused helper functions, negative boolean variable names, nested `if` statements, an unformatted Go source file (`cli/cmdssh/ssh_import_all.go`), and a Go nil-interface pitfall where functions returned concrete `*apperror.AppError` pointers assigned to `error` interfaces.

These issues violated repository linters (`golangci-lint`, nested-if linter, boolean policy check) and broke unit test suites across Linux, macOS, and Windows runners.

---

## 2. How It Happened

1. **Golangci-lint Unused & Staticcheck Warnings:**
   - Function `importMacrosLocally` in `cli/cmdssh/ssh_import_all.go` was left unused after logging refactoring moved macro import logic to `ssh_import_apply_logger.go`.
   - Helper functions `persistEnrollment`, `completeEnrollment`, and `openAndPersist` in `cli/cmdssh/sshjoin_cmd.go` were unreferenced dead code.
   - `ExecuteSSHJoinEnrollment` in `cli/cmdssh/sshjoin_enroll.go` had return type `*apperror.AppError`. When `enrollParsedTarget` called it and returned `error`, returning `nil` returned a non-nil `error` interface containing `(*apperror.AppError)(nil)`. This caused staticcheck SA4023 ("comparison is always true") and caused all `sshjoin` unit tests to report failure on successful joins.

2. **Policy Linters (Nested-If & Boolean Guidelines):**
   - 15 nested `if` statements (depth >= 2) across 10 files (`open_opener.go`, `ssh_auth_key_deploy.go`, `ssh_exec_macro_deploy.go`, `ssh_known_hosts_file.go`, `ssh_known_hosts_scan.go`, `ssh_macro_io.go`, `ssh_macro_sync.go`, `ssh_target_loader.go`, `sshexec.go`, `sshconnection.go`) violated policy checks.
   - Negative boolean names `hasNoCommandTokens` (in `ssh_exec_macro_deploy.go`) and `hasNoPass` / `hasNoUser` (in `sshconnection.go`) violated boolean naming guidelines (booleans must use `is` or `has` prefixes and must not be negative).

3. **Go Unit Test & Lint Script Failures:**
   - `test_gofmt_check_clean_repo` in `.github/scripts/tests/test_ci_scripts.py` failed because `cli/cmdssh/ssh_import_all.go` was not formatted with `gofmt -s`.
   - `TestSSHClient` in `cli/cmdssh/ssh_client_test.go` failed because default SSH flags were updated to include `-o StrictHostKeyChecking=accept-new` without updating the test expectation.
   - `TestRunCpAndRmFileCmd` and `TestRunCpDirectoryRecursive` in `cli/cmdmacro/macro_add_file_ops_test.go` failed because `extractCpPositionalArgs` in `cli/cmdmacro/macro_add_cp.go` treated any argument starting with `/` as a flag, rejecting POSIX absolute paths like `/tmp/...`.
   - `TestHandleMacroAddValidationErrors` in `cli/cmdmacro/macro_add_test.go` expected `nil` when no steps were provided interactively, but interactive macro addition returned a validation error on zero steps.
   - `TestRunSSHLogin_WithPasswordSavesEncrypted`, `TestRunSSHLogin_SubsequentLoginWithoutPassword`, and `TestRunSSHLogin_DirectIPWithPassword` in `cli/cmdssh/ssh_login_cmd_test.go` failed because `hookTestDB` returned a shared DB instance pointer whose connection was closed on the first helper exit (`defer db.Close()`), causing subsequent DB operations to fail with `sql: database is closed`.

## 3. Root Cause

1. **`cli/cmdssh/ssh_import_all.go:148`**: Unused function `importMacrosLocally`.
2. **`cli/cmdssh/sshjoin_cmd.go:305,329,341`**: Unused functions `persistEnrollment`, `completeEnrollment`, `openAndPersist`.
3. **`cli/cmdssh/sshjoin_enroll.go:267,283`**: Returning `*apperror.AppError` instead of `error` interface, causing Go typed-nil interface bug in `enrollParsedTarget`.
4. **`cli/cmdmacro/macro_add_cp.go:78`**: `!strings.HasPrefix(trimmed, "/")` check in `extractCpPositionalArgs` stripping valid POSIX paths.
5. **`cli/cmdssh/ssh_client_test.go:53`**: Missing `-o StrictHostKeyChecking=accept-new` in test expected arguments slice.
6. **`cli/cmdssh/ssh_login_cmd_test.go:25`**: `hookTestDB` returning shared DB pointer that was closed prematurely by `defer db.Close()`.
7. **`cli/cmdssh/ssh_exec_macro_deploy.go:63,76` & `cli/db/sshconnection.go:115,119`**: Negative boolean variable names `hasNoCommandTokens`, `hasNoPass`, `hasNoUser`.
8. **15 Nested-If Sites**: Unflattened control flow in 10 files.

## 5. Prevention & Learnings

1. **Go Interface Nil Pitfall:** Never directly `return someFuncReturningConcretePointer(...)` from a function returning the standard `error` interface. If the pointer is `nil`, the returned interface is non-nil. Always check `if err != nil { return err } return nil`.
2. **Affirmative Boolean Strictness:** Never use `hasNo*` or `!has*` prefixes. Always formulate booleans with positive intent (`hasMissing*`, `is*`, `has*`).
3. **Subprocess Test Construction:** In unit tests asserting CLI argument sequences, ensure the test feeds the command payload itself, allowing the builder to inject default options as intended.
