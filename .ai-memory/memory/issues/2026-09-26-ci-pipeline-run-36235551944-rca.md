# Root Cause Analysis: CI Failure 36235551944 & 36236027437

**Date**: 2026-09-26  
**CI Run IDs**: [36235551944](https://github.com/alimtvnetwork/gitmap-v28/actions/runs/36235551944), [36236027437](https://github.com/alimtvnetwork/gitmap-v28/actions/runs/36236027437)  
**Commits**: `2d13a31d`, `ce9da283`  
**Status**: Resolved  

---

### Part 1: Why It Happened
1. **Pull Efficient Test**: In commit `645a80d0`, `pull_efficient.go` began checking `git -C repo log -1 --format=%ct` to determine activity. Mock test directories in `pull_efficient_test.go` lacked `.git` repositories and commits, causing `git log` to exit with an error. The fallback assumed the repo was active, causing `TestPartitionRecordsByActivity_WithMockData` to fail.
2. **Race Detector Failure**: When migrating `gitmap sync` to `gitmap common`, `isSyncHelp` was renamed to `isCommonHelp`, but `sync_help_test.go` still called `isSyncHelp`.
3. **Truncated Python Runners**: An upstream synchronization script replaced `03-ai-scripts/06-cicd-local-runner.py` and `02-shared-engine.py` with abbreviated files, removing `chunk_items` and breaking local Python runner tooling.

---

### Part 2: How It Happened
- Tests were run without inspecting git status or validating whether mock paths satisfied the newer git commit inspection logic.
- Renaming functions across CLI commands without preserving backward compatibility wrappers led to compilation errors during race detector CI runs.
- Cross-repo automation scripts ran without dry-run validation, overwriting critical repository tools.

---

### Part 3: Root Cause
- `cli/cmdpull/pull_efficient_test.go:40-75`: directories created with `os.MkdirAll` without `git init` or timestamped commits.
- `cli/cmd/sync.go:245-265`: missing `isSyncHelp` adapter function.
- `03-ai-scripts/02-shared-engine.py` & `06-cicd-local-runner.py`: wiped out during upstream sync.
- `cli/cmd/cmd_invocation_test.go:32-120`: unmocked `cmdpipeline.PipelineAgyFixRunner` dispatched live IDE commands during automated testing.

---

### Part 4: Code Fix & Verification
1. **Mock Git Fixtures**: Created `setupTestGitRepo` in `pull_efficient_test.go` that runs `git init` and commits with `GIT_AUTHOR_DATE` set to 5 days ago (inactive) vs `time.Now()` (active). Verified test passed (`PASS 0.33s`).
2. **Sync Help Adapter**: Implemented `func isSyncHelp(arg string) bool { return isCommonHelp(arg) }` in `sync.go`. Verified `sync_help_test.go` passed (`PASS 0.00s`).
3. **Contract Restoration**: Restored `chunk_items`, `normalize_repo_rel`, `CICD_DIR`, and full 4500-line runner engine. Verified all 18 CI script tests passed (`83.19s`).
4. **Test Isolation**: Isolated `cmdpipeline.PipelineAgyFixRunner = nil` across all invocation tests in `cmd_invocation_test.go`. Verified `PASS 96.16s`.
5. **Guideline Conformance**: Eliminated 4 nested-ifs across `replay.go`, `paths.go`, `repo_create_params.go`, and `repo_create_remote.go`. Eliminated hardcoded repo path in `cli/helptext/var.md`. Formatted all Go files with `gofmt`.
