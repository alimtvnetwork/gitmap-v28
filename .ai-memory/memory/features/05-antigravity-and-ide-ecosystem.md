# Feature Catalog 05: Antigravity and IDE Ecosystem

- **Domain:** AI Agent Integration, Multi-IDE Synchronization, and Brain Preservation
- **Status:** Authoritative Capability Catalog

## 1. Google Antigravity (AGY) Integration
- Interacts with AGY agent daemon, injecting prompt templates (`is-done`) and error diagnostics.
- Discovers running IDE processes across Windows and Linux (`Antigravity.exe` / `Antigravity`).

## 2. Multi-IDE Profile Synchronization
- Synchronizes extensions, settings, and theme presets across Cursor, VS Code, and Antigravity IDE.
- Cross-node IDE delegation replicates workspace project lists across fleet machines.

## 3. Agent Brain Backup & Restore
- Automatically preserves conversation logs (`transcript.jsonl`) and decision memory to `~/.gitmap/backup/agy/`.
- Re-seeds restored workspaces upon IDE restart.
