# Historical Plans Summary: Legacy Architecture & Milestones

- **Category:** Archived Planning Reference
- **Status:** Historical Record

## 1. Overview
This document summarizes early historical planning notes from GitMap versions v3.x through v5.x:
- **v15 Database Rename Plan:** Transitioned early schema models to SQLite Split-DB architecture.
- **Force-Flatten (`gitmap cn -f`):** Automated directory un-nesting during high-speed parallel cloning.
- **Find-Next Bridge:** Integrated repository discovery probes with sequential cloning targets.
- **Templates Ignore & Attributes:** Established repository template generation with ignore presets.
- **Clone Hierarchy Audit:** Audited multi-tier directory structures during mass clone operations.
- **Generic Install Behavior:** Defined cross-platform installation manifests for Windows and Linux.
