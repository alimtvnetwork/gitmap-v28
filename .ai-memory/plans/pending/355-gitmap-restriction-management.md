# 355 GitMap Restriction Management

Slug: gitmap-restriction-management

## Tasks

- Task-01 Status clock
  Slug: gitmap-restriction-management - Task 01
  `gitmap restrict status` prints the restriction name, local time, timezone, and whether the window is open.
- Task-02 Add and edit
  Slug: gitmap-restriction-management - Task 02
  Add and edit a restriction by name, blocked-after time, email, and timezone.
- Task-03 Weekend and permit
  Slug: gitmap-restriction-management - Task 03
  `--weekend-open` / `--weekend-closed` and `--permit-stay` with `--auto-window` stamp a past morning time after the cutoff.
- Task-04 Commit-only
  Slug: gitmap-restriction-management - Task 04
  `--commit-only` keeps the restriction and skips push.
- Task-05 Settings control
  Slug: gitmap-restriction-management - Task 05
  Settings shows the restriction commands. The fullscreen control uses an icon button that changes color only.
- Task-06 Release gate
  Slug: gitmap-restriction-management - Task 06
  Minor bump is recorded. The release is postponed while the weekday window is closed.
