# Subtask 52.2: Windows Privacy, Telemetry & Theme Tweaks

## Status: pending
## Parent Plan: [52-winutil-linutil-advanced-os-integration-plan.md](../pending/52-winutil-linutil-advanced-os-integration-plan.md)

## Objective
Extend `gitmap os tweak` with WinUtil's essential tweaks in native Go: telemetry opt-out, activity history suppression, Bing search removal, and dark/light theme switching.

## Scope & Capabilities
1. **Telemetry & Activity Feed:**
   - `gitmap os tweak telemetry <off|on>`:
     - Sets `HKLM\SOFTWARE\Policies\Microsoft\Windows\DataCollection\AllowTelemetry` (0=off, 1=on).
     - Stops/disables `DiagTrack` Windows service.
     - Sets `POWERSHELL_TELEMETRY_OPTOUT=1`.
   - `gitmap os tweak activity <off|on>`:
     - Sets `PublishUserActivities` and `UploadUserActivities` to 0 in `HKLM\SOFTWARE\Policies\Microsoft\Windows\System`.
2. **Start Menu Web Search:**
   - `gitmap os tweak search <clean|default>`:
     - Sets `BingSearchEnabled=0` and `CortanaConsent=0` in `HKCU\Software\Microsoft\Windows\CurrentVersion\Search`.
3. **Dark / Light Mode Theme:**
   - `gitmap os theme <dark|light>`:
     - Windows: Sets `AppsUseLightTheme` (0=dark, 1=light) and `SystemUsesLightTheme` in `HKCU\Software\Microsoft\Windows\CurrentVersion\Themes\Personalize`.
     - Linux (GNOME): Executes `gsettings set org.gnome.desktop.interface color-scheme 'prefer-dark'|'default'`.

## Architecture
- `cli/cmdos/os_tweak_windows_privacy.go`: Pure Go registry operations for telemetry and activity feed.
- `cli/cmdos/os_theme_types.go`: Theme types.
- `cli/cmdos/os_theme_windows.go`: Windows theme registry changes.
- `cli/cmdos/os_theme_linux.go`: Linux GNOME / KDE theme changes.
- `cli/cmdos/os_theme_cmd.go`: CLI subcommand dispatch.
