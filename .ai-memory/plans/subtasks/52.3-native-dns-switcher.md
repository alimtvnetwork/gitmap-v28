# Subtask 52.3: Native Secure DNS Switcher & Benchmark

## Status: pending
## Parent Plan: [52-winutil-linutil-advanced-os-integration-plan.md](../pending/52-winutil-linutil-advanced-os-integration-plan.md)

## Objective
Implement native Go DNS management `gitmap os dns` based on WinUtil's `dns.json` to allow rapid switching between secure DNS resolvers (Cloudflare, Google, Quad9, AdGuard) with benchmarking.

## Scope & Capabilities
1. **DNS Providers:**
   - Cloudflare: `1.1.1.1`, `1.0.0.1`, `2606:4700:4700::1111`
   - Google: `8.8.8.8`, `8.8.4.4`, `2001:4860:4860::8888`
   - Quad9: `9.9.9.9`, `149.112.112.112`, `2620:fe::fe`
   - AdGuard: `94.140.14.14`, `94.140.15.15`, `2a10:50c0::ad1:ff`
   - DHCP: Reset to automatic DNS assignment.
2. **Commands:**
   - `gitmap os dns status`: Lists active DNS servers for all network adapters.
   - `gitmap os dns set <provider>`: Updates primary and secondary DNS.
   - `gitmap os dns dhcp`: Restores automatic DHCP DNS.
   - `gitmap os dns benchmark`: Measures resolution latency for all providers.

## Architecture
- `cli/cmdos/os_dns_types.go`: Provider registry and types.
- `cli/cmdos/os_dns_windows.go`: Windows `netsh` or Win32 API native configuration.
- `cli/cmdos/os_dns_linux.go`: Linux `resolvectl` or `/etc/resolv.conf` native configuration.
- `cli/cmdos/os_dns_cmd.go`: CLI subcommand dispatch.
