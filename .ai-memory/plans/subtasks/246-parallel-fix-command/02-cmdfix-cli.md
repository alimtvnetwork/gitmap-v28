- [ ] `func RunFixCmd(args []string) error` — entry point. First arg selects
      the subcommand: `encoding|newlines|naming|paths|gofmt|misspell|markdown|
      guidelines|all`. No args → parent help. Unknown subcommand → error
      listing valid subcommands PLUS the redirect line:
      `git-state remediation moved to 'gitmap stash' / 'gitmap wip' / 'gitmap discard'`.
- [ ] Flag parsing with `flag.NewFlagSet("fix", flag.ContinueOnError)`
      (same shape as `cli/cmd/llm/llm_train.go:113`):
      `-y`/`--yes`, `--workers`/`-w` (default `runtime.NumCPU()`),
      `--ext`, `--uri-pattern` (paths only), `--json`, `--no-cache`.
      (No `--category` flag — subcommands ARE the category selection.
      No `--apply` — the prompt / `-y` governs writes.)
- [ ] Validate: workers ≥ 1; scan root readable. Any failure → usage error,
      exit code 2 semantics.
- [ ] Check-driven flow per spec §2:
      1. `engine.Scan(opts)` → findings.
      2. Print MANDATORY summary (files scanned, files modified=0, per-category
         fix counts, time taken) — always, even when zero findings.
      3. If findings and the category can fix: prompt `Apply these fixes? [y/N]`
         (default N); `-y`/`--yes` skips the prompt. `naming` (report-only):
         no prompt. `--json` without `-y`: no prompt.
      4. On yes: `engine.Apply(...)` → print `Modified N files in M.MM s.`
      5. Exit codes per spec §2: 0 clean/applied · 1 findings remain ·
         2 tool error. (Follow how sibling commands signal exit codes — search
         for the established pattern; do not invent a new one.)
      6. Prompt must read from the real stdin even when stdout is piped
         (open `/dev/stdin` directly on unix; document the Windows fallback).
- [ ] `fix all`: run all 8 checks (single walk), ONE combined per-category
      summary, ONE prompt, then apply.
- [ ] `func SkillSnippetMD() string` returning the markdown block from spec
      §7 VERBATIM.
- [ ] `--help` handling: help content as Go structs (program 243 DRY rule —

## `--help` output shape (must render exactly this structure)

```
Usage: gitmap fix <category> [path] [flags]

Check-driven parallel file-hygiene fixer — native port of the 03-ai-scripts fixers.
Runs the check, prints a summary, prompts before writing.

Subcommands:
  encoding    UTF-8 no-BOM + LF normalization
  newlines    CRLF→LF, trim trailing whitespace, one final newline
  naming      boolean-comparison style audit (report-only)
  paths       Windows absolute path sanitizer (docs)
  gofmt       gofmt -w over .go files
  misspell    British→American spelling, case-preserving
  markdown    collapse 3+ blank lines in .md
  guidelines  composite: newlines + naming
  all         run every category (one summary, one prompt)

Flags:
  -y, --yes          Apply without prompting
  -w, --workers N    Worker threads (default: CPU count)
  --ext .go,.md      Only scan these extensions (default: category scope)
  --uri-pattern P    REPO_FILE_URI override for the paths category
  --json             Machine-readable report (no prompt unless -y)
  --no-cache         Bypass the scan-result cache

Flow: scan → summary (files scanned, files modified, per-category fix counts,
time taken) → prompt "Apply these fixes? [y/N]" → apply.
Exit codes: 0 clean · 1 findings remain · 2 tool error
Note: git-state remediation (stash/wip/discard) moved to
'gitmap stash' / 'gitmap wip' / 'gitmap discard'.
```
