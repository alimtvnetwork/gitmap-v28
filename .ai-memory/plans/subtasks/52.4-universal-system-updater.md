# Subtask 52.4: Universal Multi-Distro System Updater

## Status: pending
## Parent Plan: [52-winutil-linutil-advanced-os-integration-plan.md](../pending/52-winutil-linutil-advanced-os-integration-plan.md)

## Objective
Implement native Go universal system and package updater `gitmap os update` / `gitmap os upgrade` based on LinUtil's `system-update.sh` and `system-update-topgrade.sh`.

## Scope & Capabilities
1. **Multi-Distro Detection:**
   - Detect host package managers: APT, DNF, Pacman, Zypper, Flatpak, Snap, Homebrew, Winget.
2. **Commands:**
   - `gitmap os update`: Checks and updates package indices across all installed managers.
   - `gitmap os upgrade`: Performs safe non-interactive upgrade of all packages and tools.
   - `--dry-run`: Reports what would be updated without applying changes.
3. **Execution Engine:**
   - Streams live output or progress indicators.
   - Captures failures into AppError envelopes with timing summaries.

## Architecture
- `cli/cmdos/os_update_types.go`: Toolchain definitions and interfaces.
- `cli/cmdos/os_update_engine.go`: Multi-toolchain discovery and runner.
- `cli/cmdos/os_update_cmd.go`: CLI subcommand dispatch.
