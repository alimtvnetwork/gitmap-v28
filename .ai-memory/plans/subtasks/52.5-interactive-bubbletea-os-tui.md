# Subtask 52.5: Interactive Bubbletea OS TUI Dashboard

## Status: pending
## Parent Plan: [52-winutil-linutil-advanced-os-integration-plan.md](../pending/52-winutil-linutil-advanced-os-integration-plan.md)

## Objective
Design and implement an interactive keyboard-navigable terminal UI for `gitmap os` inspired by LinUtil's Rust `ratatui` dashboard and WinUtil's WPF tabs, implemented in pure Go using `github.com/charmbracelet/bubbletea`.

## Scope & Capabilities
1. **Interactive Navigation:**
   - Tabs: `[1] Tweaks`, `[2] Auto-Login`, `[3] Display / DM`, `[4] DNS & Net`, `[5] Clean & Storage`, `[6] Update`.
   - Dual-pane layout: categories on the left, interactive checkboxes `[ ]` / `[x]` on the right.
   - Status indicators: displays current live system states before and after execution.
2. **Execution:**
   - `Space`: Toggle checkbox.
   - `Enter`: Execute selected tweaks/actions sequentially with a live in-TUI progress log.
   - `q` / `Esc`: Quit.
3. **Cross-Platform:**
   - Works identically across Windows PowerShell / CMD, Linux GNOME / SSH terminal, and macOS Terminal.

## Architecture
- `cli/cmdos/os_tui_model.go`: Bubbletea model, update, and view methods.
- `cli/cmdos/os_tui_tabs.go`: Tab definitions and renderers.
- `cli/cmdos/os_tui_cmd.go`: CLI command `gitmap os tui` (or `gitmap os menu`).
