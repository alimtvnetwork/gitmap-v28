# Subtask 52.1: Display Manager Settings (Linux `dm.settings` Parity)

## Status: in-progress
## Parent Plan: [52-winutil-linutil-advanced-os-integration-plan.md](../pending/52-winutil-linutil-advanced-os-integration-plan.md)

## Objective
Implement a native Go subsystem `gitmap os dm` for Linux Display Manager inspection and session configuration (GDM3, LightDM, SDDM), satisfying the user requirement: *"I think the dm.settings, we don't have anything"*.

## Scope & Capabilities
1. **Display Manager Discovery:**
   - Detect running/enabled display manager (`gdm3`, `lightdm`, `sddm`) by reading `/etc/systemd/system/display-manager.service` or querying systemd.
   - Detect current session type (`wayland` vs `x11`) via `$XDG_SESSION_TYPE`.
2. **Wayland Toggle:**
   - `gitmap os dm wayland <enable|disable>`:
     - On GDM3: Modifies `/etc/gdm3/custom.conf` under `[daemon]`:
       - `WaylandEnable=false` to force X11 (resolves remote desktop, VM clipboard, and GPU issues).
       - `WaylandEnable=true` (or un-commented) for Wayland.
     - On LightDM/SDDM: Configures session config in `/etc/lightdm/` or `/etc/sddm.conf.d/`.
3. **DM Status Reporting:**
   - `gitmap os dm status`: Structured terminal output displaying active DM, service status, session type, autologin state, and Wayland enablement.
4. **Service Management:**
   - `gitmap os dm restart`: Restarts display-manager service.

## Architecture
- `cli/cmdos/os_dm_types.go`: Data structures and interface.
- `cli/cmdos/os_dm_linux.go`: Linux native implementation using `/etc/` file manipulation with atomic temp files.
- `cli/cmdos/os_dm_other.go`: Cross-platform stubs for Windows and Darwin.
- `cli/cmdos/os_dm_cmd.go`: CLI subcommand dispatch.
- `cli/helptext/os-dm.md`: Two-column styled help screen.
