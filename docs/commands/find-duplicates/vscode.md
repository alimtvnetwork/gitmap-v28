# `gitmap vscode find-duplicates`

Audit duplicate projects registered in the VS Code Project Manager extension (`projects.json`).

## Usage

```bash
gitmap vscode find-duplicates
gitmap find-duplicates vscode
```

## Remediation Commands

```text
Remediation & Fix Commands for VS Code:
──────────────────────────────────────────────────────────────────────────
● Fix All Together (Deduplicate & clean):
  gitmap vscode optimize-projects
```
