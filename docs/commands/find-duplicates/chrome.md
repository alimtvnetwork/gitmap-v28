# `gitmap chrome find-duplicates`

Audit duplicate Chrome browser profile records and offline copies.

## Usage

```bash
gitmap chrome find-duplicates
gitmap find-duplicates chrome
```

## Remediation Commands

```text
Remediation & Fix Commands for Chrome:
──────────────────────────────────────────────────────────────────────────
● Fix Single (Delete specific profile):
  gitmap chrome-profile-delete <profile-name>

● Fix All Together (Optimize):
  gitmap chrome-profile optimize-projects
```
