## 3. Hard rules (non-negotiable, all waves)

- `gitmap aum search` / `gitmap find` / `gitmap cat` / `gitmap ps` / `gitmap py` /
  `gitmap llm train` ONLY. TOTAL BAN on grep/rg/git grep/Select-String.
- RELATIVE paths only in every artifact. NEVER absolute paths.
- NEVER commit binaries. NEVER delete files. ALIASES ARE KEPT (no pruning).
- Files ≤300 lines. No `go test` locally.
- Atomic `gitmap cpf "<module> - <summary>"` (hyphen, NO colons). Every commit
  MUST push (verify with `git ls-remote`).
- Dumb-terminal safety: piped output must not corrupt (no ANSI in pipes).
- Mindset (`.ai-memory/what-to-read.md`): DRY — single source of truth for
  help text, themes, colors; enforcement beats documentation.

## 4. Current-state facts (ground truth)

- Theme modes today: `bright` (default, bright+bold passthrough),
  `standard` (muted pre-v5.13 downgrade), `monochrome`/`mono` (strip all SGR).
  Resolution: `--theme` flag → `GITMAP_THEME` env → `constants.ThemeDefault`.
  Implementation: `cli/termout/theme_theme.go`, `cli/termout/filter.go`,
  `cli/cmd/themeflag.go`, `cli/cmd/outputwriters.go`.
- Help infra: `cli/cmd/help.go`, `cli/cmd/helpcheck.go`, `cli/helpdoc/*.md`
  (generated by `03-ai-scripts/51-helptext-generator.py`).
- No `merge write` / `mr` command exists at HEAD (full-repo search, 0 hits).
- Virus ground truth: commit 385aba38e removed VirTool:MSIL/Subti.C heuristic
