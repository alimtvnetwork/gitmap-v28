# 347 - GitMap User Change Command Specification

This specification suite governs the implementation of user identity switching commands (`change-user`, `change-login`, `autobot`) and the machine identity migration to "AI automation bot".

## Documents
- `01-architecture-spec.md`: Top-level CLI routing, dispatcher architecture, and argument parsing.
- `02-component-spec.md`: Component contracts, `cli/cmduser` handlers, and `cli/usercontext` identity management.
- `03-migration-and-verification-spec.md`: Machine Git configuration migration, help menu updates, and release ceremony.
