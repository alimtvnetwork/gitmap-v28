# gitmap devtool (Alias for gitmap devtools)

See full documentation in [gitmap devtools](file:///cli/helptext/devtools.md).

## Usage

```bash
gitmap devtool [flags]
```

## Examples

```bash
# Render cache hierarchy tree in dry-run mode
gitmap devtool --tree --dry-run

# Output discovered caches in JSON
gitmap devtool --json
```
