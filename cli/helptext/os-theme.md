# gitmap os theme

Switch desktop appearance between Dark Mode and Light Mode across Windows and Linux.

## Usage

```bash
gitmap os theme <mode>
```

## Modes

| Mode | Description |
|------|-------------|
| dark (d) | Set desktop and application windows to dark mode |
| light (l) | Set desktop and application windows to light mode |
| status (st) | Inspect current active visual appearance |
| help | Display help and usage information |

## Examples

### Switch to Dark Mode

```bash
gitmap os theme dark
```

### Switch to Light Mode

```bash
gitmap os theme light
```

### Inspect Theme Mode

```bash
gitmap os theme status
```
