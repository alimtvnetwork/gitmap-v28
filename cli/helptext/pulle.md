# gitmap pulle (Alias for gitmap pull-error)

See full documentation in [gitmap pull-error](file:///cli/helptext/pull-error.md).

## Usage

```bash
gitmap pulle [repo-slug|all] [flags]
```

## Examples

```bash
# Query current repo pull error
gitmap pulle

# Query all repo pull errors
gitmap pulle all

# Output JSON
gitmap pulle --json
```
