# gitmap cluster set-path-alias

Map a cross-platform path alias on a cluster node.

## Usage

```bash
gitmap cluster set-path-alias --id <id> --alias <name> --path <target-path>
```

## Examples

```bash
gitmap cluster set-path-alias --id 3 --alias "work" --path "/var/www/projects"
```

See also: `gitmap cluster set-default-path`, `gitmap cluster`
