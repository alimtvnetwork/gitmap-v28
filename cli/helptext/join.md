# join

`gitmap join` connects a worker node to an active orchestrator cluster daemon or enrolls remote machines into the cluster topology.

## Usage

```bash
# Daemon mode (join local machine as a worker client to an orchestrator daemon):
gitmap join <IP>:<PORT> --token <TOKEN>

# SSH cluster node mode (enroll a remote machine into your cluster registry):
gitmap cluster join <user@ip|ip> [alias] [flags]
gitmap cluster node add <user@ip|ip> [alias] [flags]
gitmap cluster add <user@ip|ip> [alias] [flags]
```

## Description

The `join` command connects worker nodes into a cohesive GitMap cluster:
- **Daemon Join**: Connects the current machine to a running `gitmap serve` orchestrator daemon over secure TLS, registering this machine as a client worker in the cluster.
- **Cluster SSH Node Join**: Enrolls a remote target machine into your cluster registry for remote execution (`cluster exec`), scripts (`cluster run-script`), and provisioning (`cluster node <recipe>`).

## Options

- `--token <TOKEN>`: Cluster authentication token generated by `gitmap serve`.
- `--port <PORT>`: Target port (defaults to daemon port or 22 for SSH).
- `--push-auth`: Automatically push local SSH public key to remote authorized_keys.
- `--no-probe`: Skip upfront network and connectivity verification.

## Examples

### 1. Connect Local Node to Orchestrator Daemon
```bash
gitmap join 192.168.1.10:9999 --token a1b2c3d4e5f6
gitmap join orchestrator.local:9999 --token my-cluster-secret
```

### 2. Enroll Remote Machines into Cluster Topology
```bash
# Enroll by IP with alias
gitmap cluster join 192.168.1.20 devbox

# Enroll with username and alias
gitmap cluster join ubuntu@192.168.1.21 worker-1

# Enroll with password and push SSH keys
gitmap cluster node add root@192.168.1.22 master --push-auth
```

### 3. List Registered Cluster Nodes
```bash
gitmap cluster nodes
gitmap cluster nodes --json
```

See also: `gitmap cluster`, `gitmap cluster add`, `gitmap cluster node`, `gitmap servers-clients`, `gitmap ssh-join`
