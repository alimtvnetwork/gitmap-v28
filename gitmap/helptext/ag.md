# ag — Antigravity Workspace Management (Alias)

Alias for `gitmap antigravity` / `gitmap agy`.

## Subcommands

- `gitmap ag group`: Manage and prompt project groups.
- `gitmap ag undo`: Revert the last clear or project removal action.
- `gitmap ag redo`: Reapply the undone workspace action.
- `gitmap ag plugin`: List and install Antigravity plugins.
- `gitmap ag settings`: Export and import configuration settings.
- `gitmap ag ls`: List Antigravity projects.

## Examples

```bash
gitmap ag group ls
gitmap ag undo
gitmap ag plugin ls
```
