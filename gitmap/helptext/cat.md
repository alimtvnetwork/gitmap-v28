# cat

Display file contents cleanly in the terminal across all operating systems.

## Aliases

`view`, `type`

## Usage

    gitmap cat <filepath>

## Description

The `cat` command provides a clean, cross-platform file reader that works identically on Windows PowerShell, macOS, and Linux without shell-specific quirks. It expands paths, environment variables, and tildes.

## Examples

```bash
# View contents of a configuration file
gitmap cat .env

# View a project markdown file
gitmap cat readme.md
```
