# gitmap ct (Prompt Architect)

Manage and install Prompt Architect v2 in any repository.

## Usage
```bash
gitmap ct install-prompts [targets...]   # Install/update Prompt Architect
gitmap ct update-prompts [targets...]    # In-place update prompts
gitmap ct status [targets...]            # Check prompt status in repositories
gitmap ct version [targets...]           # Show Prompt Architect version
gitmap install-prompts                   # Alias for current repo
```
