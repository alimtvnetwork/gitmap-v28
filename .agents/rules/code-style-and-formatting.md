# Rule: Code Style & Vertical Spacing

1. **Vertical Spacing:** Mandatory blank line before `if` statements, after closing brace `}`, before `return`, and around multiline struct calls.
2. **Zero Nesting:** Conditional nesting depth must not exceed 1. Flatten all blocks using guard clauses and early returns.
3. **Size Limits:** Functions <= 15 lines max (<= 8 lines preferred). Files <= 100 lines coding (recommend <= 80 lines). React components <= 100 lines.
4. **Lowercase Files:** All filenames and directories must be strictly lowercase (e.g., `readme.md`, `changelog.md`).
