# Command Development for Release Tag Management

Autonomously audit, identify, and remove orphan or broken GitHub releases and git release tags that lack proper binary assets, published releases, or have failed CI/CD pipelines, supporting dry-run and non-interactive confirmation via `gitmap fix release tags`.
